# Weight-Converter

This is a simple Java console program for converting weight between pounds and kilograms

When you run the program it shows two options

1 Lbs to Kgs
2 Kgs to Lbs

You are asked to choose one of the options by entering a number

If you choose 1 you can enter a value in pounds and it will be converted to kilograms

If you choose 2 you can enter a value in kilograms and it will be converted to pounds

If you enter anything else the program shows an error message

The conversion formulas used are
1 pound equals 0.45359237 kilograms
1 kilogram equals 2.20462262 pounds

All logic is written in Main.java

This program is made for basic practice with Scanner and simple calculations in Java
